Button Loudness Scale

Andrés Guerrero · September 29, 2026

Our buttons and links, ranked from loudest to quietest, following Viget's Loudness Guide. Loudness is separate from meaning. Each row is how much attention an element asks for, and the gaps are where we have nothing to offer.

Why this exists. On the TradeMaster landing page, feedback asked for a more prominent Join CTA. The only option louder than Secondary was the orange Purchase button, which we reserve for commerce. The team approved orange as an exception, and this scale is meant to open the conversation about the gap behind that decision.

02

Gaps across every level

These don't belong to one row. They limit how loud any button can get.

GapWhat happens todayTo discuss
No loudest level Nothing sits above Secondary except Purchase, so promotional CTAs borrow orange. What does Scream look like for us, and where is it allowed?
Colored surfaces No inverse button. The white-filled version looked "broken" on the TradeMaster and Day Saver banners. Link already has an inverse option; Button doesn't. Inverse versions of each button, or one inverse button designed properly?
Size Buttons are a fixed 343px wide in Figma, with no size options. "Larger button, larger font" has no approved answer. Add a size scale so size can make a button louder, not only color.
Meaning vs. loudness Each level is tied to a meaning. Orange means "this buys something," so we can't make something louder without changing what it means. Does orange mean purchase only, or conversion (purchase plus enrollment)?
Frequency In Viget's guide, louder elements show up less often. Our loudest button shows up the most, so an orange promo only stands out on pages with no Add to Cart. Should the loudest level be rare by rule?
